## Project Description

This project is an AI-based Emotion Detection Application developed using Python, Flask and IBM Watson Natural Language Processing.

The application analyzes text and identifies five emotions:
- Anger
- Disgust
- Fear
- Joy
- Sadness

It also identifies the dominant emotion in the given text.
